# PDFs simplificados disponíveis para o NotebookLM

Esta checklist reúne **todas as 54 apostilas simplificadas atualmente disponíveis no catálogo do curso**, uma por aula, com link direto para o Google Drive.

## Como usar

- Baixe somente o arquivo com nome `Aula XX_Apostila_Simplificada.pdf`.
- Não adicione a apostila normal e a simplificada da mesma aula ao mesmo notebook: o conteúdo é redundante.
- Organize um notebook por disciplina; em Português, Raciocínio Lógico e Engenharia de Software, divida em dois se o NotebookLM ficar lento.
- Use o resumo para a primeira passagem e os quizzes para diagnosticar lacunas. Consulte vídeo ou apostila completa somente quando os erros persistirem.
- Esta lista contém tudo o que existe em versão simplificada, mas não cobre todas as 115 aulas com apostila do catálogo.
