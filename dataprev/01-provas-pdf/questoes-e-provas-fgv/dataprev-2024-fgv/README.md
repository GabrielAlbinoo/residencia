- Comece pelo `tipo-01` como simulado completo.
- Use o gabarito definitivo para correcao.
- Depois compare os tipos 2, 3 e 4 para treinar variacoes e revisar enunciados.
- Registre erros em `../../../05-revisoes-e-erros/caderno-de-erros.md`.
