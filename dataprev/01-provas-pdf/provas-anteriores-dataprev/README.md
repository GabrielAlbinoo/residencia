# Provas anteriores Dataprev

Acervo de provas anteriores para treinar o concurso Dataprev 2026, com foco em Analista de Tecnologia da Informacao - Desenvolvimento de Software.

## Ordem recomendada de uso

1. `2024-fgv-desenvolvimento-software/`: prioridade maxima, mesma banca do edital 2026 e cargo equivalente.
2. `2023-cebraspe-desenvolvimento-software/`: bom para conteudo de TI, mas estilo de prova diferente, com itens certo/errado.
3. `2014-quadrix-analista-ti/`: treino complementar de Analista de TI, mas nao e tao aderente quanto 2024 e 2023.
4. `2012-quadrix-desenvolvimento/`: util para conteudo historico de desenvolvimento, mas usar com menor peso porque banca e edital sao antigos.
5. `2009-coseac-construcao-de-sistemas/` e `2006-cespe-construcao-de-sistemas/`: provas historicas, boas para garimpar conceitos recorrentes, mas sem prioridade.

## 2024 - FGV

Fonte: pagina oficial FGV Dataprev 2024 - https://conhecimento.fgv.br/concursos/dataprev24

Arquivos:

- `dataprev-2024-edital-fgv.pdf`
- `dataprev-2024-desenvolvimento-software-tipo-01.pdf`
- `dataprev-2024-desenvolvimento-software-tipo-02.pdf`
- `dataprev-2024-desenvolvimento-software-tipo-03.pdf`
- `dataprev-2024-desenvolvimento-software-tipo-04.pdf`
- `dataprev-2024-gabarito-definitivo-fgv.pdf`

Como usar:

- Fazer primeiro o tipo 01 em modo prova.
- Usar os tipos 02 a 04 como treino dirigido, porque tendem a ser variacoes do mesmo caderno.
- Conferir pelo gabarito definitivo.

## 2023 - Cebraspe

Fonte: pagina oficial Cebraspe Dataprev 2023 - https://www.cebraspe.org.br/concursos/dataprev_23

Arquivos:

- `dataprev-2023-edital-cebraspe.pdf`
- `dataprev-2023-conhecimentos-gerais-nivel-superior.pdf`
- `dataprev-2023-desenvolvimento-software-conhecimentos-especificos.pdf`
- `dataprev-2023-gabarito-definitivo-conhecimentos-gerais-nivel-superior.pdf`
- `dataprev-2023-gabarito-definitivo-desenvolvimento-software.pdf`

Como usar:

- Lembrar que o Cebraspe cobra certo/errado; nao comparar acerto bruto diretamente com FGV.
- Usar para revisar conceitos de desenvolvimento, seguranca, banco de dados, governanca e legislacao.

## 2012 - Quadrix

Fonte alternativa: Estude Gratis, que aponta o concurso Quadrix 2012 e disponibiliza prova, edital e gabarito.

Pagina consultada: https://www.estudegratis.com.br/provas/quadrix-2012-dataprev-analista-de-tecnologia-da-informacao-desenvolvimento

Arquivos:

- `dataprev-2012-edital-quadrix.pdf`
- `dataprev-2012-desenvolvimento-prova.pdf`
- `dataprev-2012-desenvolvimento-gabarito.pdf`

Como usar:

- Usar como treino complementar.
- Nao priorizar tecnologias antigas acima do edital 2026.
- Aproveitar principalmente Portugues, logica, conceitos de desenvolvimento e banco de dados que continuam atuais.

## 2014 - Quadrix

Fonte alternativa: Etica Concursos / PCI Concursos.

Pagina consultada: https://eticaconcursos.com.br/provas/quadrix-2014-dataprev-analista-tecnologia-da-informacao

Arquivos:

- `dataprev-2014-edital-quadrix.pdf`
- `dataprev-2014-analista-ti-prova.pdf`
- `dataprev-2014-analista-ti-gabarito.pdf`

Observacao:

- A prova baixada aparece como Analista Tecnologia da Informacao, perfil Infraestrutura e Aplicacoes. Use como treino geral de TI e banca Quadrix, nao como espelho direto do Perfil 3 de 2026.

## 2009 - COSEAC/UFF

Fonte alternativa: Qconcursos.

Pagina consultada: https://www.qconcursos.com/questoes-de-concursos/provas/coseac-2009-dataprev-analista-de-tecnologia-da-informacao-construcao-de-sistemas

- `dataprev-2009-construcao-de-sistemas-prova.pdf`

## 2006 - Cespe

Fonte alternativa: Etica Concursos / Qconcursos.

Pagina consultada: https://eticaconcursos.com.br/provas/cespe-2006-dataprev-analista-de-tecnologia-da-informacao-construcao-de-sistemas

Arquivos:

- `dataprev-2006-construcao-de-sistemas-prova.pdf`
- `dataprev-2006-construcao-de-sistemas-gabarito.pdf`

Observacao:
