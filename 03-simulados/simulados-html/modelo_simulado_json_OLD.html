Modelo de Simulado

Carregue um JSON, responda as questões e finalize para conferir o resultado.

Carregar perguntas

O JSON importado e suas respostas ficam salvos neste navegador, mesmo se voce atualizar ou fechar a pagina.

Formato esperado do JSON 
{
  "titulo": "Simulado - Semana 1",
  "blocos": [
    {
      "id": 1,
      "titulo": "Sistemas Numericos",
      "revisao": "aulas/1-binarios.md"
    }
  ],
  "questoes": [
    {
      "id": 1,
      "bloco": 1,
      "tema": "Conversao binaria",
      "pergunta": "Quanto vale 1010 em decimal?",
      "opcoes": ["8", "9", "10", "12"],
      "correta": "C",
      "explicacao": "1010 = 8 + 2 = 10."
    }
  ]
}

Os campos blocos, tema, explicacao e revisao sao opcionais. O modelo tambem aceita os nomes em ingles usados no simulado existente: blocks, questions, topic, prompt, options, correct e explanation.
