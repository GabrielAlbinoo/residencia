# Simulados

Guarde aqui:

- Simulados em HTML ou Markdown.
- Logs de desempenho.
- Controle de notas e tempo.

Subpastas:

- `simulados-html/`: simulados interativos ou arquivos HTML.
- `resultados/`: pasta correta para relatorios e revisoes de simulados.

Regra: nao salve resultados na raiz da pasta de estudos. Use sempre `03-simulados/resultados/`.
