# Resultados de simulados

Esta e a pasta correta para salvar qualquer resultado de simulado.

## Raiz atual

Todos os resultados de simulados da residência devem ficar dentro de:

```text
C:\Users\gabrieloliveira\Documents\pessoal\estudos\residencia\03-simulados\resultados
```

A pasta pai `C:\Users\gabrieloliveira\Documents\pessoal\estudos` não deve receber resultados diretamente.

## Estrutura

- `relatorios/`: relatorio completo gerado no final do simulado.
- `revisoes/`: pasta especifica de cada simulado com `revisao_erros.md`, diagnostico, exercicios e gabaritos.
- `outros/`: arquivos que nao se encaixarem nas duas categorias acima.

## Regra para novos simulados

Quando um simulado for corrigido, salve:

```text
C:\Users\gabrieloliveira\Documents\pessoal\estudos\residencia\03-simulados\resultados\relatorios\simulado_NN_assunto_YYYY-MM-DD.md
C:\Users\gabrieloliveira\Documents\pessoal\estudos\residencia\03-simulados\resultados\revisoes\resultados-simulado-NN-YYYY-MM-DD\revisao_erros.md
```

Nao crie mais pastas `resultados-simulado-*` na raiz da pasta pai `estudos/`.
